# 📱 Gerador / Leitor de QR Code

Aplicação desenvolvida para geração e leitura de QR Codes, integrada no ecossistema do projeto do squad.

---

## 🚀 Funcionalidades

* 📌 **Geração de QR Code:** Criação rápida de códigos QR a partir de textos, URLs ou dados dinâmicos.
* 🔍 **Leitura/Escaneamento:** Leitura de QR Codes utilizando a câmara ou ficheiros de imagem.
* 🎨 **Interface Intuitiva:** Layout simples, moderno e focado na experiência do utilizador (UX).
